# Currency Conversion API

## Description
A REST API built using Node.js HTTP module and Express.js that converts USD, EUR, and CNY to RWF.

## Endpoints

### GET /convert

Example:
http://localhost:2000/convert?amount=50&currency=usd

## Supported Currencies
- USD
- EUR
- CNY

## Features
- Input validation
- Error handling
- Middleware (Express version)

## How to Run

### HTTP Server
node http-server.js

### Express Server
node express-server.js
